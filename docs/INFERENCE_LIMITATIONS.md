# 저장 모델 추론의 성능 한계

단일 파일 추론과 기존 배치 결과의 일치는 **계산 경로의 일치**를 검증합니다. 새 데이터에 대한 유효성이나 실사용 성능을 보장하지 않습니다.
기존 성능 수치는 [날짜 예비 실험](DATE_PRELIMINARY_RESULTS.md)의 9/19 시험 결과이며 이번 작업에서는 다시 학습하거나 임계값을 조정하지 않았습니다.

| RPM | AE 정상 오탐률 | OCSVM 정상 오탐률 | IF 정상 오탐률 |
| --- | ---: | ---: | ---: |
| 900 | 51.00% | 100.00% | 71.00% |
| 1200 | 97.98% | 100.00% | 100.00% |
| 1800 | 74.51% | 78.43% | 50.98% |

정상 오탐률이 높으므로 출력 Abnormal만으로 실제 고장이라고 단정할 수 없습니다.
날짜 간 정상 분포 변화와 작은 Train 표준편차에 대한 분석은 [정상 CH3 날짜 분석](NORMAL_CH3_DATE_ANALYSIS.md)에 있습니다. 원인을 센서나 운전 상태 하나로 단정하지 않습니다.
공통 정규화 비교안은 채택하지 않았으며 [비교 결과](AE_NORMALIZATION_COMPARISON.md)는 보존합니다.

- 실제 Run 경계는 미확정입니다. 저장 모델은 날짜 그룹 예비 실험이며 독립 Run 검증을 대체하지 않습니다.
- 시험 데이터를 이미 분석했습니다. 후속 설정 결정에 활용한 결과는 개발 과정으로 기록하고 독립 최종 시험과 구분해야 합니다.
- 시험 파일의 약 79–80%가 이상입니다. 높은 AP는 정확도나 낮은 오탐률을 의미하지 않습니다.
- 학습 당시의 고정 형식·길이·샘플링 주파수와 900/1200/1800RPM만 지원합니다. 호출자가 RPM을 정확히 제공해야 합니다.
- 센서 위치·단위·장착 상태가 다른 자료는 동일한 배열 형식이라도 분포가 다를 수 있습니다. 물리적 적합성을 자동 확인하지 않습니다.
- 모델별 점수 절댓값은 서로 비교할 수 없습니다. 각 모델의 저장 임계값과 함께 해석해야 합니다.
- 결함 종류·원인 추정, 센서·베어링 사양 기반 판정, DAE는 이번 추론 기능의 범위에 포함하지 않습니다. [최소 웹 화면](STREAMLIT_APP.md)은 업로드·미리보기·분석·결과 표시와 [SQLite 이력](SQLITE_HISTORY.md)을 지원합니다. 이력 저장은 탐지 성능을 개선하거나 고장 원인을 증명하지 않습니다.

책임님 피드백, 실제 Run·센서·운전 정보와 분리된 시험 데이터 확보 후 본 실험을 설계해야 합니다. 이번 결과를 보고 임계값이나 모델 설정을 추가 탐색하지 않았습니다.
