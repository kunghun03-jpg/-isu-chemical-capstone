`features.py`, `auxiliary.py`, `combined.py`는 추가 분석이며 가이드 기본 결과와 구분합니다.
Run이 미확정인 상태에서는 파일 수를 기준으로 독립 Run을 만들어내지 않습니다.

Looseness 상태로 통일하여 처리하며 원본 경로는 보존합니다.
전체 원본 품질검사 결과는 DATA_QUALITY_REPORT.md와 outputs/data_preparation에 기록합니다.

세 모델의 학습·평가 진입점은 Run 모드 분할, 확정 ID, 파일별 8개 구간과 NPZ 메타데이터를 검사합니다.
일반 Run·파일 모드의 미확정 ID는 차단합니다. 날짜 예비 실험은 별도 모드로 날짜 배정을 검사하고
run_id는 비워 두며 date_group을 보존합니다. 모델과 데이터의 식별값도 비교합니다.
Autoencoder의 구조·손실·학습 설정·Q95 수식은 유지하고 실행 전 검사와 식별 정보만 추가했습니다.
