현재 기본 모델에는 잡음을 추가하지 않습니다. 책임님 피드백에서 필요성이 확인되면 별도 실험으로 계획합니다.

- **입력 자료:** 발표자료·논문 설정과 구현 재현 범위에 대한 책임님 의견.
- **실행 조건:** 기본 모델/Run 분할/평가 규칙 고정 후 선택 실험 승인. 이번 작업에서는 구현하거나 실행하지 않음.
- **변경 범위:** 잡음 추가 효과만 비교할지, Welch·800성분·모델 구조 등 발표자료 전체를 재현할지 먼저 구분. 여러 요소를 동시에 바꾼 결과를 잡음 하나의 효과로 해석하지 않음.

- **산출물/완료 기준:** 별도 실험 이름·설정·모델·같은 평가 지표의 비교표와 한계. 기존 기본 결과를 덮어쓰거나 결함 시험 결과에 맞춰 설정을 사후 선택하지 않음.

## 4. 미확정 사항과 다음 확인 항목

**현재 미확정:** 책임님 피드백, 실제 Run 경계·독립성, 날짜/RPM 간 같은 운전의 연결 여부,
학습·검증·시험 배정, 새로운 날짜 일반화와 같은 평가 목적, 반복 실험 범위, Denoising 비교 추가 여부.
Normal3 기본 제외와 현재 전체 6채널 품질검사 정책은 구현된 기본값이며, 바꾸려면 책임님 의견과 근거를 기록해야 합니다.

**향후 확인:** 운전/취득 일지, Normal1/2/3 의미, 센서/베어링/재조립 이력, 파일 간 실제 중첩 여부,
실행 환경·자원, 품질검사 이후 원본 변경 여부, 비교표/발표 수치와 실제 결과의 대응.
측정 묶음 18개(Normal1/2) 또는 24개(Normal3 포함)를 독립 Run 수로 그대로 보고하지 않습니다.

책임님 피드백 이후 첫 작업은 **피드백을 실험 결정 기록으로 정리하고, 데이터 제공자에게 Run 식별 근거를 확인하여 분할 설계안을 작성하는 것**입니다.
확정 전에는 Run ID·split을 채우거나 실제 학습/최종 평가를 시작하지 않습니다.
