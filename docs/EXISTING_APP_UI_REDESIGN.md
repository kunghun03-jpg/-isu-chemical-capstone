# 기존 Streamlit 앱 UI 개편

## 진입점과 변경 범위

현재 다중 모델 화면의 실제 진입점은 **streamlit_app_v3.py**다. 기존 docs/V3_MULTI_MODEL_DASHBOARD.md와 docs/V3_RESPONSIVE_DIAGNOSTICS.md의 실행 명령을 확인했다. 별도 pages 디렉터리를 사용하는 대신 이 파일의 메뉴 분기로 화면을 표시한다.

이번 변경은 이 기존 파일과 기존 UI 모듈 vibration/v3_presentation.py를 직접 수정한다. 신규 앱·V4·별도 실행 시스템·새 프레임워크/의존성을 추가하지 않는다. 이전 streamlit_app.py/streamlit_app_v2.py도 수정하지 않는다. 기존 V2는 공유 구성·상세 표시·이력 API로 재사용한다.

- 네이비 사이드바: 분석하기 / 분석 이력 / 모델 정보 / 사용 가이드
- 좌측 입력 카드: 실제 MAT 업로드, RPM, 분석 실행
- 우측 요약 카드: RPM / 분석 상태 / AE 운영 판정 / 원시 AE MSE
- 모델별 카드: AE / OCSVM / IF / DAE 상태와 실제 점수
- 하단 좌측: 시간 파형·FFT·포락 분석·회전 성분 탭
- 하단 우측: 실제 관측 특징·RF 참고 예측과 최종 후보·실제 보류 사유·권장 조치·저장/다운로드
- 기존 상세 보기: AE 입력 스펙트럼·구간별 근거 유지

기존 메뉴의 기능도 유지한다. 통계·리포트는 분석 이력의 펼침 영역, 성능 비교·읽기 전용 설정은 모델 정보에 있다. 이전 메뉴명이 세션에 남아 있으면 대응하는 새 메뉴로 이동한다.

## 판정·데이터 안전

종합 판정은 기존 운영 AE 결과다. 별도 앙상블·평균·점수 정규화·모델 투표를 도입하지 않는다. 이상 점수는 **원시 AE 복원 MSE**이며 정규화 점수·신뢰도가 아니다. OCSVM의 0과 음수 threshold 등도 저장 결과 그대로 표시한다. 원래 score > threshold 판정은 바꾸지 않는다.

DAE 공개 로더·RPM 검사는 그대로다. 차단된 DAE는 “사용 중지 / 검증 필요”로 표시하고 점수·임계값을 만들어 표시하지 않는다. 실제 차단 원인과 환경/파일 상태는 모델 상세 및 모델 정보에서 확인한다. 지원 범위를 등록하지 않는다.

AE 정상일 때 RF 생략, AE 이상일 때 RF 참고 예측, 최종 후보 보류 정책을 유지한다. 메인 요약과 상세 보기에서 원시 예측/최종 후보를 구분하고 실제 보류 사유를 표시한다. RF 막대그래프는 상세 영역에 유지하며 미보정 모델 점수라고 명시한다. 특정 결함을 권장 조치 문구에서 확정하지 않는다.

기존 history_store/save_references/read_references 및 candidate_reports 경로를 사용한다. 운영 DB 스키마/저장 코드/모델/학습 코드/manifest/threshold/전처리를 변경하지 않는다. 저장·중복 처리·JSON 다운로드·이력 CSV 다운로드·기존 기록 조회를 유지한다.

## 신호 시각화의 의미

- 실제 업로드 CH3만 사용한다. 화면용 min/max 축약은 실제 표본을 고르고 분석 입력은 변경하지 않는다.
- FFT는 기존 Hann 단측 진폭이다. ASD나 속도 스펙트럼으로 바꿔 부르지 않는다.
- 기존 EDA analyze_signal의 포락 스펙트럼을 재사용한다. 포락 시간 파형은 같은 4차 Butterworth 2–8kHz, 양방향 필터, Hilbert 절댓값, 양끝 0.1초 제외를 표시 전용으로 계산한다. 기존 RF 특징이나 모델 입력은 변경하지 않는다. 테스트에서 EDA 포락 FFT·RMS 일치를 확인한다.
- 기존 EDA 대역의 현장 타당성과 베어링 형상/특정 결함 주파수는 미검증이다. 포락 피크로 IR/OR/Roller를 확정하지 않는다.
- 검증된 속도 적분 경로가 없어 속도 파형을 추가하지 않는다. raw/raw²·무차원 표기를 사용하며 m/s² 또는 mm/s를 붙이지 않는다.
- 1X/2X/3X는 명목 RPM/60×차수다. 회전 성분 탭에서 기존 1X–5X의 실제 피크 값을 확인한다. 1200RPM의 1X는 20Hz다.

## 실행

기존 실행 환경과 환경변수를 그대로 사용한다. 프로젝트 루트에서 **기존과 같은 명령**이다.

```bash
"$HOME/capstone-web-venv/bin/python" -m streamlit run streamlit_app_v3.py
```

별도 테스트 worktree에서 사용하는 명령도 파일명이 같다. 임시 브라우저 시험만 포트를 18546으로 바꿨으며 운영 명령은 바꾸지 않았다. CSS는 Streamlit 기본 st.html을 사용하고 기존 네이티브 위젯을 유지한다. 화면 소스 변경 후 기존 서버를 재시작해 새 스타일을 확인한다.

패치 파일을 이용할 경우 프로젝트 루트에서 먼저 적용 가능성을 검사한다. 충돌 시 기존 변경을 덮어쓰지 않는다.

```bash
git apply --check /다운로드/경로/existing-app-ui-redesign.patch
git apply /다운로드/경로/existing-app-ui-redesign.patch
```

실제 WSL MAT·운영 가중치는 Codex에 없다. 브라우저 캡처와 자동 테스트는 합성 MAT·임시 모델 fixture·임시 SQLite만 사용한다. 모델 성능 검증이나 실제 설비 판정 성공을 주장하지 않는다.

## 검증

신규 테스트 tests/test_existing_app_redesign.py는 4개 메뉴, AE 원시 값 불변, DAE 숫자 미표시, 포락 EDA 수치 일치, 분석/저장/다운로드/이력, 시각화 오류 시 AE 유지, AE 정상 시 RF 생략, RPM 변경 초기화를 확인한다.

```bash
"$HOME/capstone-web-venv/bin/python" -B -m unittest \
  tests.test_existing_app_redesign tests.test_dashboard_v3 tests.test_v3_diagnostics
```

기존 V2/V3/AE/RF/DAE 차단/저장·이력 등을 포함한 회귀 테스트 72개 통과. RF 재학습 호출을 차단한 상태에서 실행했다. 기존 V3 탐색 테스트의 메뉴명만 새 위치로 수정했으며 모델/저장 검증은 유지했다.

브라우저 확인 항목: 1920×1080, 1366×768, 390×844. 카드의 가로 넘침·모델 카드와 펼침 영역 겹침, 좁은 화면 세로 배치와 네이티브 사이드바 접근, 실제 버튼·탭·저장/중복 저장·JSON 다운로드·이력·RPM 변경 초기화·콘솔 오류를 확인한다. 캡처는 합성 데이터 결과로 구분한다.

## 사용자 WSL 최종 확인

1. 기존 DB를 백업하고 테스트 전용 DB를 ISU_CHEMICAL_HISTORY_DB로 지정한다. 기존 모델 경로/후보 보류 환경변수는 그대로 유지한다.
2. 실제 Normal1/2, IR/OR/Roller, Unbalance, Looseness MAT를 업로드한다. 날짜/RPM도 바꿔 본다.
3. AE 점수·threshold·판정이 기존 기록과 같은지 확인한다. OCSVM/IF 결과와 DAE 차단 상태를 확인한다.
4. AE 정상에서 RF 생략, 이상에서 RF 원시 예측과 보류 결과가 분리되는지 확인한다.
5. FFT 전체/저주파, 실제 포락, 1X–5X, AE 입력 스펙트럼 상세 보기를 확인한다.
6. 저장/중복 저장/다운로드 후 서버를 재시작해 같은 DB의 이력을 재조회한다. 원본 MAT/파형은 DB에 저장하지 않는다.
7. 오류 파일, 누락 모델, 파일/RPM 변경도 확인한다. 운영 모델이나 DB를 수정해 시연 결과를 맞추지 않는다.

최종 브라우저 결과: 세 해상도 모두 위 흐름 통과, 콘솔 오류 0, 가로 넘침 없음, 모델 카드 겹침 없음. 마지막 모바일 CSS 수정 후 선택 테스트 16개와 float32 포락 수치 테스트를 재실행해 통과했다. 이 수는 기존 72개와 중복되며 별도 실제 성능 시험이 아니다.
