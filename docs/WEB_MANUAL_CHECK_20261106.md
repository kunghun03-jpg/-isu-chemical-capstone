## 2. 9/12 결함 라벨 파일의 정상 판정: 미탐 의심

사용자가 결함 폴더에서 선택했다고 보고한 파일을 데이터 목록과 실제 원본으로 대조했습니다. 파일명만으로 상태·RPM을 추정하지 않았습니다.

- 파일: `20260912_170916_Vib.mat`
- 실제 원본 경로: `data/20260912/20260912_900RPM/Looseness0.1/Vib/20260912_170916_Vib.mat`
- `manifests/run_inventory_unconfirmed.csv`: 날짜 **20260912**, RPM **900**, 상태/원본 상태 **Looseness0.1**, `is_normal=0`. Run ID·split은 빈칸.
- 기존 품질 목록: pass, `(6,65536)`, 25600Hz, NaN·Inf·극단값 없음.
- 원본·품질 목록·DB #2 SHA256 일치: `1f35acbb5f92c3612cc0bd3cd6b0fb0cb350fb876c92fe78ab4ddb702bbead4e`.
- 저장 웹 분석 시각: **2026-11-06 22:38:16 KST**, 채널 CH3, 실험 `date_prelim_20261106`.

같은 원본을 기존 CLI로 재추론하고 DB #2의 웹 결과와 숫자·판정을 직접 비교했습니다.

| 모델 | 웹 저장 점수 = CLI 파일 점수 | 저장 파일 임계값 | 웹·CLI 판정 |
| --- | ---: | ---: | --- |
| AE | 0.2231166508363574 | 0.3242139731159553 | 정상 |

3개 모델 모두 **점수·임계값·판정이 정확히 일치**했습니다. 입력 파일 SHA256과 번들 ID도 일치합니다.
CLI: `python -m scripts.infer_mat --file "위 원본 경로" --rpm 900 --model all`.
웹 표시 오류를 뒷받침하는 차이는 발견되지 않았습니다. 데이터 목록의 결함 라벨을 기준으로는 세 모델의 **미탐(FN) 의심 사례**입니다.
폴더·목록 라벨은 확인됐지만 해당 측정의 실제 기계 상태나 결함 강도를 독립적으로 재확인한 것은 아닙니다.

이 파일은 기본 날짜 예비 실험의 시험 파일이 아닙니다. 9/12에는 Normal1·Normal2만 학습에 사용했으며 이 결함 파일은 학습에도 사용하지 않았습니다.
이번 사례를 기존 9/19 시험 집계에 추가하거나, 이 한 파일을 맞히도록 임계값을 낮추지 않습니다.

3. 실제 Run 경계, 센서·운전 이력, 상태 라벨의 물리적 근거 확인이 필요합니다. 날짜 그룹을 독립 Run으로 간주하지 않습니다.
4. 공통 정규화 비교안은 채택하지 않았으며 기존 주파수별 기준과 두 실험 결과를 유지합니다. 시험 자료를 이미 본 상태이므로 추가 분석은 개발 분석으로 명시합니다.
5. DAE는 팀원 담당입니다. 현재 AE·OCSVM·IF 구현 범위를 유지하고 이후 연결 시 입력·정규화·점수·임계값·저장 형식을 검토합니다.
